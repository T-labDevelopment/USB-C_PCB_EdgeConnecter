## 旧検討案：BT1 CH25-2032LF基板直付け（Rev.0.5時点、現在は非採用）

> この節から下の旧Rev.0.5設計履歴は現在の採用仕様ではありません。Rev.0.6では外付けCR2032＋標準2線パッドが正式な接続方式です。

秋月電子 [販売コード100706](https://akizukidenshi.com/catalog/g/g100706/) のCR2032基板取付ホルダー `CH25-2032LF` に変更しました。旧Keystone用フットプリントは使用しません。新規`USB_C_Test_Parts.pretty`内の正規寸法図ベースの専用フットプリントに変更し、PCB側に電気端子用穴2個（20.0mmピッチ）、位置決めNPTH穴3個を追加しました。

**極性とPCB表裏方向はまだ実物確認前です。** 現在は下側リードをBAT_POS、上側をBAT_NEGとして仮定しています。設計確定前に電池を抜いた状態で金属クリップと2端子の導通を実測してください。詳細：[BT1 CH25-2032LF実装資料](docs/BT1_CH25-2032LF.md)。

PCBは依然として銅箔配線がありません。KiCad 10によるERC/DRC、実装、機械的嵌合は未検証です。

**以下は旧Rev.0.5時点の設計説明です。** ユーザー提示の左右2端子・中央電池・信号別LEDという概念図に基づき、14Pと10Pを1枚に統合し、ケーブルを挿入するだけで各信号の導通状態がLEDで見えるように再構成しました。

| 項目 | 14P検証（上段） | 10P検証（下段） |
| --- | --- | --- |
| USB-C接点 | J1（送出）、J2（受け） | J3（送出）、J4（受け） |
| VBUS | R1→D1 | R5→D5 |
| CC1/CC2（共用） | R2→D2 | R6→D6 |
| USB D+（A6/B6） | R3→D3 | 非搭載 |
| USB D−（A7/B7） | R4→D4 | 非搭載 |
| GND | J1→ケーブル→J2の共通帰路 | J3→ケーブル→J4の共通帰路 |

電源はBT1のCR2032（公称3V）1個。各LEDには22kΩを直列に接続し、入力スイッチ、制御IC、USB PD回路を置きません。

**実際の導通経路（14PのVBUS例）**

`CR2032＋ → R1 → J1 VBUS → 外部C-Cケーブル → J2 VBUS → D1（A→K） → J2 GND → 外部C-Cケーブル → J1 GND → CR2032−`

10PのVBUS/CC、および14PのCC/D+/D−も同様に、それぞれの抵抗とLEDを通ります。GNDは戻り線です。**J1とJ2、J3とJ4を基板上で直接配線しない**ので、未接続のケーブルは導通扱いになりません。電池の＋と−の不要な交差は避けてあります。

**重要：これは電気的な論理構成が成立することの検証です。** KiCad 10でのERC実行・DRC・実機嵌合・LED光量試験を実施したという意味ではありません。PCBの銅箔配線は依然0本で、製造しても動作しません。

## LEDと信号の対応

| 系統 | LED | 確認する信号 | 同一機能として集約するパッド |
|---|---|---|---|
| 14P（J1⇄J2） | D1 | VBUS | A4/A9/B4/B9 |
| 14P（J1⇄J2） | D2 | CC | A5(CC1)/B5(CC2) |
| 14P（J1⇄J2） | D3 | D+ | A6/B6 |
| 14P（J1⇄J2） | D4 | D− | A7/B7 |
| 10P（J3⇄J4） | D5 | VBUS | A4/A9/B4/B9 |
| 10P（J3⇄J4） | D6 | CC | A5(CC1)/B5(CC2) |

GND（A1/A12/B1/B12）は14Pと10Pで独立した**共通の帰路**として使います。基板内で戻り側GND（J2/J4）をBAT_NEGに直結していないため、ケーブルのGND経路が断線した場合は、その系統のLEDがまとめて消灯します。GNDだけの独立LEDは設けません。

**同じ機能の端子はLEDを共用**しますが、14Pと10Pでは検証対象が違うため、同じVBUSやCCであっても系統間でLEDを共用しません。片方のケーブルだけが接続されたときにもう一方の表示が点灯しないようにするためです。

### 回路経路（各LED共通）

`CR2032+ → R1～R6(各22k) → J1/J3側の該当信号 → C-Cケーブル → J2/J4側の該当信号 → D1～D6（アノード→カソード） → 戻り側GND → C-CケーブルのGND → CR2032−`

接続した信号と共通GNDの両方に導通があれば、対応するLEDだけが点灯します。抜けば消灯します。2本同時接続時には最大6灯が点灯します。

## 判定上の制限

- **e-marker付きのパッシブケーブルは検証対象から除外します。** この簡易治具はCC1/CC2を直結しているため、ケーブルのVCONN側Ra（約1kΩ）に影響され、正常なケーブルでもCC LEDが点灯しない可能性があります。e-marker非搭載の一般的なUSB 2.0 C-Cケーブルを基準に評価してください。

- 表裏のA/B端子や複数VBUS・GND端子を並列接続しているため、**同一信号群内の個別パッド1個の断線は判別できない場合があります**。
- CCは一般のC-Cケーブルで1本の有効信号線です。A5/B5の両方をこの**無電源ケーブル検証専用基板**では意図的にまとめています。実製品のUSB-CデバイスではCC1とCC2を直結せず、規格どおりの終端を使用してください。
- LED点灯は簡易導通確認であり、接触抵抗の定量評価、隣接信号短絡の網羅的検出、USB2.0列挙、USB PD、ESP32の書き込み成功を保証しません。
- ケーブルの**両端をそれぞれ反転**して、点灯の変化と接触安定性を確認してください。

## 電源・安全

22kΩで赤色LED順方向電圧を約1.8Vと仮定すると、1灯あたり約0.055mA、6灯で合計約0.33mAです（**計算上の参考値で実測ではありません**）。CR2032の標準連続負荷0.2mAより大きいため、挿入試験は短時間とし、使用後はケーブルを抜いて消灯させてください。低電流でも見える赤色LEDの部品選定・光量は実機確認対象です。

**この基板は外部のUSB機器に接続できません。** CR2032による電圧をUSB端子に出す検証治具です。PC、充電器、モバイルバッテリー、給電中のUSB機器、アクティブケーブル等に接続しないでください。無通電の受動型C-Cケーブルのみを試験対象とします。
