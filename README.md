# USB-C PCB Edge / KiCad 10 / Rev.0.3

基板に直接形成するUSB Type-C受け口です。ESP32の組立時USB書き込み、および簡易電源を目的とします。シルク印刷による補強、後端取付端子、固定穴はありません。

## Rev.0.4 側面ラッチ・銅箔保護の改善（2026-10-23）

- 14P／10PフットプリントにKiCad 10のRule Areaを各4個追加し、左右ラッチ近傍の不要な配線・ビア・GNDベタ等の流入を防止します。\`F.Cu\`/\`B.Cu\`とも適用。
- 重要：**GND接点とEdge.Cutsの最短距離約0.17mmは変更しておらず、JLCPCBの通常ルーター加工目安0.20mmに届きません**。金端子の特例加工可否は要確認で、メーカー製造承認済みではありません。
- USB接点、6.2mm突出長、0.8mm公称板厚、パッドの番号・電気属性、Edge.Cuts、シルクなしの仕様は変更しません。
- 追加したKeepoutが実際に基板に反映されることとKiCad DRCの認識は、実PCB内で確認する必要があります。
- 詳細は [Rev.0.4保護エリア・製造精度確認](docs/FOOTPRINT_SAFETY_REV04.md) を参照してください。

## 2026-10-23 先行事例・規格照合（形状を無断変更せず検証課題を整理）

- [国内外先行事例と寸法監査](docs/PRIOR_ART_AUDIT_2026-10-23.md)・[接点座標の数値監査](docs/GEOMETRY_AUDIT_2026-10-23.csv)・[実機試験判定計画](docs/MATING_ACCEPTANCE_TEST.md)を追加。
- **0.8mm公称厚**は設計の標準値だが、USB-IFが記載するレセプタクル舌片の公称0.70mmとは異なる。国内の0.8mm製作例は存在するが本版の嵌合は未確認。
- **6.2mmの突出長はUSB規格上の舌片長ではない**。6.2mmはシェルの有効長の値から採用した仮説であり、実機で挿入深さと接点導通を検証する。
- **10Pの簡易給電フットプリントは正式なUSB Type-C Power-Onlyレセプタクル接点要件を満たさない**。実験用途の非規格版として区別する。規格準拠を重視する給電用途には14P構成を再検討する。
- ラッチ付近に非GND導体を置かず、外形加工・面取りの可否を製造メーカーに確認する。
- 電極銅箔とEdge.Cuts座標、シルク無し、後端取付端子無し、ユーザー指定のピン表示規則は本監査で変更しない。

## Rev.0.3 : ピン番号の機能併記

- PCBエディターでも機能が分かるよう、シンボルの**ピン番号**とフットプリントの**パッド番号**を共通して `USB-C原番号+機能名` に変更しました。例：`A1GND`、`A4VBUS`、`A5CC1`、`A6D+`、`A7D-`。
- **A1はGND、VBUSはA4/A9/B4/B9**です。例示の`A1VBUS`はUSB-Cの正式な割当と異なるため使用しません。
- KiCadのシンボル**ピン名**（`GND`、`VBUS`、`D+`など）および電気的種別、銅箔・カットライン・板厚0.8mmは変更しません。
- 独自のパッド番号に変更されるため、**旧版のシンボルだけ、またはフットプリントだけを置き換えると番号不一致**になります。既存回路に組み込まれている場合は両者を同時更新し、PCBのネット割当を確認してください。
- 標準USB-Cの端子番号は`docs/pinout.csv`に別欄で保持し、改名規則を`docs/PIN_LABELS_REV03.md`に記録しています。

## 標準基板厚の指定

- **標準基板厚は公称0.8mm**。14P USB 2.0書き込み版と10P電源版の双方に適用します。
- 基板仕様は原則として **FR-4・2層・接点ENIG** とします。メインPCBに一体化するUSB-Cエッジ端子です。
- 0.6mmは公開元の試作実績がある比較・代替案として残しますが、標準採用しません。0.8mmで嵌合できない場合にのみ個別に再評価します。
- 参考資料の0.8mm設計例と、**本Rev.0.2の実物による適合検証済み**という意味は異なります。現段階の0.8mm嵌合・通信・書き込みは未検証です。

## Rev.0.2 の変更

- **差し込み長4.315 → 6.200mm（+1.885mm）**。接点を先端とともに前方へ1.885mm移動し、接点寸法・先端との位置関係・側面のラッチ溝は維持します。首の直線部を延ばした形状です。
- 14P（USB 2.0）/ 10P（給電）とも、**両面基板、Edge.Cutsの切欠きのみ、F.SilkS/B.SilkSなし、後端接続ランドなし**。
- 端子シンボルのERC属性を設定：VBUS・GND＝`power_in`、D+/D−・CC1/CC2＝`bidirectional`。`docs/pinout.csv` にピン番号・用途・電気的属性を記載。
- 機械寸法と試作検証条件は `docs/MECHANICAL_REV02.md` を参照してください。

**重要**：6.20mmはUSB Type-Cのシェル有効長を参考にした暫定寸法で、シェルのないPCBエッジ端子の嵌合を保証する規格寸法ではありません。公称0.8mmを標準板厚とし、試作品で実際の挿入深さ・導通を確認してください。0.6mmは必要時の代替比較対象です。KiCad ERC/DRC・実挿抜・実USB書き込みは未検証です。


KiCad 10.x用のPCB一体型USB-Cレセプタクル・ライブラリです。**試作・未検証**です。完成した製品では通常使用せず、ESP32の製造時ファームウェア書き込み、および必要に応じた簡易給電に使うことを想定します。

## ライブラリ

| 種類 | シンボル | フットプリント |
| --- | --- | --- |
| USB 2.0書き込み用 | `USB_C_PCB_Edge_14P_USB2_NoShield` | `USB_C_Edge_14P_USB2_NoSilk` |
| 給電専用 | `USB_C_PCB_Edge_10P_Power_NoShield` | `USB_C_Edge_10P_Power_NoSilk` |

- 2層基板に対応する表裏接点。14Pは各面7接点、10Pは各面5接点。
- **コネクター反対側の取付パッド、固定穴、実装用ランドは設けない**。
- **F.SilkS/B.SilkSにコネクター外形枠を設けない**。
- `Edge.Cuts` はUSB差込部の切り欠きだけで、採用先PCBの外形と接続して閉じる必要があります。
- 基板厚は公称0.8mmを標準とします。元の公開形状は0.6mmでの試作記録がありますが、改訂版の0.8mm実嵌合・書き込みは未検証です。
- 金属シールド端子のないPCB端子なので、KiCad標準USB-Cシンボルの機械的なS1端子を除いた派生物です。

## KiCadへの導入

採用先のKiCadプロジェクトへ `USB_C_PCB_Edge.kicad_sym` と `USB_C_PCB_Edge.pretty/` をコピーし、`sym-lib-table` と `fp-lib-table` の登録行を**追加**してください。既存のライブラリテーブルを上書きしないでください。

このフットプリントは単独で閉じたPCB輪郭を作りません。ローカル座標の端点 **(-0.635, -4.450)** と **(-0.635, +4.445)** から採用先PCBのEdge.Cutsに接続します。ケーブル挿入端はX負方向です。

### USB2.0 14P配線

| PCB接点 | 接続 |
| --- | --- |
| A1, A12, B1, B12 | GND |
| A4, A9, B4, B9 | VBUS |
| A5 | CC1（5.1kΩでGNDへ） |
| B5 | CC2（5.1kΩでGNDへ） |
| A6, B6 | D+ |
| A7, B7 | D− |

CC1とCC2にはそれぞれ独立したRdが必要です。ESP32-S3やESP32-C6などネイティブUSB書き込み対応品向けです。初代ESP32などは別途USB-UART変換を要します。VBUSをESP32の3.3V端子へ直接接続してはいけません。

### 給電専用10P

USB2のデータ用4接点を省略し、VBUS・GND・CC1・CC2だけを設けます。5V超のUSB PD給電にはPD受電コントローラーが必要で、コントローラー内蔵CC終端と外付け抵抗の二重実装には注意してください。

## 製造・検証状態

- **KiCad 10での実読み込み、ERC、DRC、Gerber、JLCPCBでの実製造、挿抜、USB通信、PD交渉は未検証**。
- ENIGを候補とし、HASLのような厚い仕上げは避けます。端面切削公差、保持力、ラッチとの接触は試作評価が必要です。
- 通常の1.6mm厚基板へそのまま適用することはできません。
- シルクによる厚み補助を除いているため、参照した公開設計より接触保持力が低くなる可能性があります。
