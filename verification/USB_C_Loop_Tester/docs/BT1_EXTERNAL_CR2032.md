# Rev.0.6 — 外付けCR2032電源の採用仕様

## 変更目的

CH25-2032LF（秋月電子販売コード100706）の基板直付けフットプリント使用時の形状・配置・ライブラリ管理・極性未確定問題を解消する。USB-C 14P/10P 6灯式導通検査の電気仕様を維持し、電池だけを**外付けホルダーからの2線給電**に変更する。

## KiCad 標準フットプリント

`Connector_Wire:SolderWire-0.25sqmm_1x02_P4.2mm_D0.65mm_OD1.7mm`

出典: https://github.com/KiCad/kicad-footprints/blob/master/Connector_Wire.pretty/SolderWire-0.25sqmm_1x02_P4.2mm_D0.65mm_OD1.7mm.kicad_mod

- 標準の2線はんだ付けパターン、端子間隔4.2mm。
- 各電気パッド径1.85mm、ドリル径0.85mm。銅パッド形状・CourtyardはKiCadの公開データと整合。
- 適合するリード線は想定0.25mm²クラス（導体外径約0.65mm）であり、実際の被覆・撚線の導体径に応じて選定する。
- パッド1＝BAT_POS＝＋、基板座標（76.0,90.0）mm。
- パッド2＝BAT_NEG＝−、基板座標（80.2,90.0）mm。
- 回路図では標準 `Device:Battery_Cell` を維持し、BT1は外部電池を表現する。実際のPCB上にはホルダー本体・コイン電池を取り付けない。

## 使用する外部ホルダー

CR2032×1個用の2極ホルダーであれば形式は問わない。前に指定されたCH25-2032LFを使用する場合は、ホルダー端子2か所へ適切な絶縁リード線をはんだ付けし、ケースや治具へ別途固定する。CH25は本来THT直接実装用なので、外付け配線加工の機械強度・絶縁方法はメーカー保証仕様ではなく組立工程で検証すること。

**電池を外した状態でホルダー端子と金属接点の導通を実測し、＋／−を確認してから配線する。** 図面からプラス端子の位置は確定できない。バッテリーを装着した状態でホルダーを加熱・はんだ付けしない。

## 取り付け手順

1. 外部ホルダーの極性をテスターで確認し、リード線を識別する。
2. ＋をBT1パッド1、−をBT1パッド2へはんだ付けする。
3. 電池ホルダーを別途固定する。主基板の電極パッドには引張・捩り荷重を掛けないよう、リードを絶縁固定する。
4. 電池非装着で＋／−短絡がないことを確認し、CR2032を装着する。
5. **無通電の受動型USB-C to Cケーブルだけ**を接続してLED点灯を確認する。パソコン・USB充電器・USB電源には接続しない。

## 変更されない仕様と未検証事項

- 14P J1/J2：VBUS、CC、D+、D−でLED D1～D4を共用表示。
- 10P J3/J4：VBUS、CCでLED D5～D6を共用表示。
- R1～R6は22kΩ、CR2032は1個、スイッチなし。
- 6灯同時点灯時の電池消費は赤LED順方向電圧1.8Vを仮定すると約0.33mA。実測・光量確認は未実施。
- PCBの17フットプリント・74電気パッド・全16ネットは変更なし。CH25の位置決めNPTH穴3か所を削除。
- **基板内の配線は0本で、現時点では製造・動作可能な完成基板ではない。KiCad 10ネイティブERC/DRCは未実施。**
