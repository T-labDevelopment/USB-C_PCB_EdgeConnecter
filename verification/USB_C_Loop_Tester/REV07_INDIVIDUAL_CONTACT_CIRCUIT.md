# Rev.0.7 個別USB-C接点専用LED回路への変更記録

日付：2026-11-12／作業ブランチ：`feature/usb-c-individual-pad-led-rev07`。

## 要件と設計方針
従来Rev.0.6のVBUS・CC・D+/D−・GNDの信号グループ共用配線を撤回し、**接点ごと**に独立した直列22kΩ抵抗と赤色LEDを追加した。14P J1/J2は14回路、10P J3/J4は10回路、合計24回路。GND接点も個別系統化し、LEDカソードを共通電池マイナス（BAT_NEG）に接続する。USB-Cパッド同士は基板上では一切共通化しない。

## 独立回路構成
`CR2032(+) → Rn(22kΩ) → J1/J3の指定された1接点 → 検証対象ケーブル → J2/J4の指定された同名1接点 → Dn(アノード端子2→カソード端子1) → CR2032(-)`

各Rnのパッド1は共通BAT_POS、各Dnのパッド1は共通BAT_NEG。これらは電源供給に必要な**意図的な共通ネット**であり、USB接点のネットはそれぞれ `SRC_J1_...` / `DST_J2_...` / `SRC_J3_...` / `DST_J4_...` で完全分離する。

- R1/D1～R14/D14: 14Pコネクター対、14系統
- R15/D15～R24/D24: 10Pコネクター対、10系統
- `channel_map_rev07.csv` に全24回路のピン対応を記録

## 元のデータから維持する事項
- 14P/10Pそれぞれ2個のUSB-Cエッジ接点形状、端子番号、ラッチ用Keepout、銅接点寸法は変更なし
- FR-4 0.8mm・2層・ENIG設計基準は変更なし
- 外付けCR2032ホルダー＋標準2線はんだ付けパッドを維持（BT1位置は配線・部品配置のため31.0,18.0mmに移動）
- 標準 `Device:R` / `Device:LED` / `Device:Battery_Cell` のライブラリ定義は改変なし
- USB-C検証用プロジェクトシンボルのみ、従来重ねていた全ピンを異なる位置の受動ピンへ変更。シンボル正式ライブラリと回路図キャッシュを双方同期

## 制約：各LEDが必ず1接点の通電を意味するわけではない
通常のUSB Type-Cケーブルの両端プラグ内部では、複数VBUS端子とGND端子が互いに接続される。したがって、本治具ではPCB上のネットを分離していても、**ケーブル側の共通化を通じたバイパス通電**が発生する。各LEDの点灯だけで各VBUS/GNDピン1個の接触不良を確実に識別することはできない。

USB 2.0 Type-Cケーブルプラグでは一般にB6/B7接点を設けないため、J1/J2のB6/B7に割り当てたD11/D12系統は、正常なUSB2.0ケーブルでも点灯しない可能性がある。CCはケーブルの表裏方向やe-markerの有無で経路が変わるため、A5/B5が両方同時に点灯することは合格条件にできない。

**この検証基板は各PCBエッジ接点の分離配置を評価する試作治具であり、USB-C標準ケーブルの接点1本ずつの良否を保証する測定器ではない。** 24灯全点灯を正常の合格条件にしない。仕様書で保証されないPIN対応のLEDは「参考表示」として扱う。

出典：
- USB-IF Type-C Cable & Connector Specification（USB2 cable assembly wiring と内部VBUS/GND共有、B6/B7）：https://www.usb.org/sites/default/files/USB%20Type-C%20Spec%20R2.0%20-%20August%202019.pdf
- Microchip Type-C Cables and Connectors：https://developerhelp.microchip.com/xwiki/bin/view/applications/usb/typec-features/cable-connector/

## 電池・視認性
CR2032 3.0V・赤色LEDのVf=1.8Vを仮定した計算：1系統 `(3-1.8)/22000=約0.055mA`、24系統同時点灯時は約**1.31mA**。Panasonic CR2032の標準連続負荷0.2mAを大きく上回る。LED光量・電池電圧降下・抵抗値の適否は未実測なので、必ず短時間で試験する。より大きな実用電流を必要とする場合は電源構成を別途再検討する（今回の要求ではCR2032を変更しない）。
参考：https://energy.panasonic.com/jp/business/products/lithium/coin-cr-standard/models/CR2032

## 静的検査の範囲
- シンボル配置：J1～J4、BT1、R1～R24、D1～D24＝計53個
- PCBフットプリント：53個、銅パッド146個、信号グループ独立ネット48本＋電源2本＝50ネット
- 回路図：全24回路に専用抵抗・LED、146個のグローバルラベル
- PCB側：未配線（track 0）、via 0
- PCB部品配置は仮案。銅箔配線、GND plane、シルク干渉、エッジ寸法公差は未検証
- KiCad 10によるネイティブERC/DRCおよび実機試験は未実施。エラー0・警告0と断定しない
- 旧Rev.0.6の6灯回路は元ブランチに保持。mainへの統合は別途

## 試験上の注意
電池を装着した状態でPC、充電器、USB PD機器、給電中USB機器へ接続しない。無通電の受動型USB-Cケーブルのみで確認し、挿入方向と表裏を切り替えて記録する。
