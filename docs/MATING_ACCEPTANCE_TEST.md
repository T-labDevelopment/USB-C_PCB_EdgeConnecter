# USB-C PCB Edge嵌合/通電試験 計画（実機未検証）

対象：公称0.8mm・2層・ENIG、14P書き込み版（優先）と10P電源簡略版（試験用）。
現行6.2mm突出部の「短くて刺さり切らない」不具合を最優先で判定する。

## 合格基準

1. **製造図面**：Edge.CutsがメインPCB外形に連結して閉輪郭を形成。切り欠き・端子接点・ソルダーマスク抜き・スルーホール/ビア/非GND銅箔の側面接近を製造データで点検。製造元の外形加工可否を確認。
2. **実測板厚**：接点部の実測板厚を個体ごとに記録（公称0.8mmだけで合格にしない）。金メッキ後の盛り上がりも確認。
3. **無通電・差し込み**：異なるメーカーのUSB-Cケーブルを最低2種類使用。各表裏向きで、**工具や異常な押し込み力を用いず**奥まで挿入できるか、肩/筐体が先に当たらないか、金属部が接点以外を擦らないか確認。写真を撮影する。
4. **絶縁・導通**：通電前にVBUS-GNDの短絡なし、CC1-CC2の意図しない短絡なし、D+-D-の短絡なしをチェック。ケーブル接続中に各接点の導通が維持されるかを確認する。
5. **5V接続試験**：電流制限付きUSB電源で、CC1/CC2の別々のRdによる認識とVBUS供給を確認。意図しない高電圧を印加しない。
6. **ESP32書き込み試験（14P）**：PCからUSB列挙、書き込み、リセット/再接続に成功すること。少なくともケーブル2種類×表裏両向きで実施し、試験結果を個別に記録。
7. **軽い保持状態**：ケーブル自重や作業中の小さな揺れで瞬断しないこと。無理なこじり試験・高電流・高電圧・連続運用試験はこの用途では行わない。

**重要な観察ポイント**：
- 突出長6.2mmでプラグが奥まで入るか、逆に内部で底突きや引っ掛かりを起こさないか。
- 表裏のどちらか一方しか認識しない場合、接点位置・CC接続・D+/D-結線を別々に切り分ける。
- 実測0.8mm前後で挿入が硬すぎる／緩すぎる場合、寸法基準の見直し判断材料とする。
