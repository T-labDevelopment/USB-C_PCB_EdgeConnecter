# USB-C PCB Edge 実証用ボード Rev.T1 — 回路・基板構成（設計案）
更新: 2026-11-10 / 対象: KiCad 10.x 安定版

## ステータス
**構成検討・製造照会準備**。回路図、PCB、Gerberは未作成。KiCad 10 ERC/DRC、メーカー承認、実機試験はすべて未実施。本書は製造指示書ではない。

## 目的
既存Rev.0.4フットプリントを**変更せず**、基板厚0.8mm・2層FR-4・ENIGと6.2mm差込長の嵌合、向き別のCC認識、5V VBUS供給、14PのUSB2通信を確認する。調達元に製造可否を照会後、接点/エッジ/保持力の実測と改版判断を行う。

## Rev.T1 の電気回路（Device / Sink, USB PDなし）
14P:
- 既存シンボルに含まれる `A1GND,A12GND,B1GND,B12GND` → GND。
- `A4VBUS,A9VBUS,B4VBUS,B9VBUS` → `USB_VBUS_5V`（テスト点および外部USBデバイスの5V入力へ）。ESP32の3.3Vへ直結不可。
- `A5CC1` → CC1測定点、抵抗R1=5.1kΩ→GND。`B5CC2` → CC2測定点、抵抗R2=5.1kΩ→GND。**CC1/CC2を直接短絡しない。**
- `A6D+,B6D+` → `USB_DP`、`A7D-,B7D-` → `USB_DM`。両面をコネクタ近傍で合流させ、分岐スタブが長くならないように配置する。
- J2: 2.54mm 1x6ヘッダ（仮）を `1=USB_VBUS_5V, 2=GND, 3=USB_DP, 4=USB_DM, 5=CC1, 6=CC2` とする。ピン1および表裏方向をシルクに明記する。USB2のHS通信品質はこのブレークアウト接続では保証しない。主検証はFull Speed以下の既知良品USBデバイス。
- チップ上にUSBデバイスICは実装しない。**J2に既知良品のUSB2 Device評価基板を接続して初めてUSB列挙試験が成立する**。J2はホスト機器や別の5V源と直結しない。
- 必要ならデバイス側でESD保護/適正なVBUSデカップリングを設ける。Rev.T1の目的を曖昧にしないため、14P coupon単体に大きな入力コンデンサ・スイッチング電源は置かない。

10P:
- 電源/CCは上記と同様。J2は1x4ヘッダ（`1=VBUS,2=GND,3=CC1,4=CC2`）。
- 必要に応じて独立した負荷端子へ外付け抵抗を接続する。初回は無負荷電圧・CC動作のみ評価し、負荷試験は電流制限を設定してから行う。
- 10Pを**USB Type-C規格準拠Power-Onlyレセプタクル**と表記しない。VBUS 5Vのみ、PD高電圧/大電流を試さない。

## PCB機械・レイアウト計画
- 既存フットプリントのEdge.Cutsを**そのまま使用**する。プラグ差込方向はローカルX負方向。基板外形は既存Edge.Cutsの二つの終点 `(-0.635,-4.450)` と `(-0.635,+4.445)` に**座標一致**で連結し、単一閉輪郭を作る。既存の独自寸法の僅かな上下非対称を勝手に修正しない。
- 同じ設計外形の候補は「根元の本体部約50×50mm + 差込突出6.2mm、全長約56.2mm」。JLCPCBのGold Fingersサービスに掲示される50×50mm下限を踏まえた**照会用案**であり、この構成で正式受理されると断定しない。小型化はメーカー承認後に検討。
- リードイン面取りは**現状なし**。加工業者が提案する面取りは接点損傷・端子幾何変化につながるため無断追加しない。
- 0.8mm・2層・1ozを基準とし、F/Bの接点をENIG・マスク開口・ペースト無しとする。ソルダーマスク・シルク・配線・ビア・ベタは差込部とラッチKeepoutに入れない。
- 接点裏側近傍にR1/R2、ヘッダと個別CC測定点を配置。テストヘッダや部品はプラグの金属ハウジング/ラッチの掃引領域から離す。
- USB2のA/B合流点までのスタブは最短に。D+/D-の配線は幅/間隔を基板厚・実積層構造に合わせて検討し、少なくともFull Speedを優先。必要に応じデータ信号の測定専用バージョンを別途作る。
- ネット名は `USB_VBUS_5V, USB_DP, USB_DM, USB_CC1, USB_CC2, GND`。シンボル端子、配線、**グローバルラベル**はKiCad 50mil格子に合わせる。適切な電源供給源属性／PWR_FLAGを検討し、ERC 0件・警告0件を目標にする。
- **既知の製造懸念**：Rev.0.4 GNDパッドとEdge.Cuts間の最短約0.17mmはJLCPCBの通常ルーター基準0.20mmに満たない。フットプリント形状は改変せず、製造先へ例外可否を照会する。回答次第で別改版を検討する。

## 検証方法
1. **製造前**：KiCad 10.x GUIでライブラリ実読込、パッド番号/ネット、Edge.Cuts閉輪郭、ルールエリア、基板設定、Gerber/Drillを確認。ERC/DRC結果を保存する。製造元へ0.17mmとENIG・細いラッチ溝の可否を問い合わせる。
2. **無通電**：接点部実測板厚、実測突出長、表裏接点位置、バリ・ラッチ切欠き、異なるUSB-Cケーブル2本の表裏嵌合/保持を観察する。ケーブルを無理にこじらない。
3. **無通電導通**：VBUS-GND、CC1-CC2、D+-D-、隣接接点の短絡なし。各CC-GNDはそれぞれ約5.1kΩ。既存USBデバイス接続前にピン配列をテスターで照合。
4. **制限付き5V**：まず過電流保護のある電源または保護USBハブに接続。想定以上の負荷/高温/不安定な接触があれば中止。CC1/CC2観測点で向きごとに接続側が切り替わること、VBUSが5V級で出ることを確認。
5. **14P USB2**：既知良品のFull Speed以下のDevice基板をJ2に接続し、PCで列挙・再接続・ファイル転送/シリアル通信等を2ケーブル×表裏で試験。J2はUSB hostへの直結ではない。
6. **記録**：`TEST_RECORD_TEMPLATE.csv`にボードID、ケーブル、向き、各実測、写真/ログの参照、可否を記録。不合格時は「嵌合/接点/CC/電源/データ」を切り分ける。無人高電流・20V PD・無理な挿抜耐久試験は対象外。
