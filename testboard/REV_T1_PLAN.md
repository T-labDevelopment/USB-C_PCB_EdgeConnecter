# USB-C PCBエッジ検証基板 Rev.T1 — 単一PCB・2端子・LED/USB通信試験
更新日: 2026-11-10 / KiCad 10.x安定版を基準 / ステータス: **構成設計案**

## 0. 変更点とスコープ
2026-11-10の要求により、旧案の「14Pと10Pの2枚の基板」「外付けUSB Device評価基板をJ2へ接続」の2項目を**撤回**する。**1枚のPCBの反対側に既存Rev.0.4の2種類のUSB-Cエッジ端子を1個ずつ配置**し、内蔵LEDと手はんだしやすいUSB-UART ICによって単独で試験可能とする。

**対象は既存ライブラリの形状検証である。** `USB_C_PCB_Edge.pretty` と `USB_C_PCB_Edge.kicad_sym` の正式な元データ/パッド番号/Edge.Cuts/0.8mm/6.2mmは改変しない。試験基板は現行USB-C形状の準拠認証や製品定格を保証しない。

## 1. 基板外形と端子
- **1 PCBだけ**。外形の暫定案は約**60 × 50 mm**（両端突出部を含む）。FR-4、2層、板厚公称0.8mm、銅1oz、F/B端子はENIG、端子上はレジスト/シルク/ペーストなし。0.6mm試作品や別パネルを標準比較対象にしない。
- 基板の**左短辺**にJ1=14P USB 2.0（通信・給電）、**右短辺**にJ2=10P Power（非規格の比較用）。双方の舌片が外向き。端子の周囲に部品やシルクを置かず、プラグハウジングが基板に干渉しない空間を設ける。
- 左側の既存フットプリントは無回転、右側は平面内180°回転（ミラーではない）。双方のローカルX負方向が基板外側を向くように配置。元のF.Cu/B.Cu面は維持する。
- 60mmを左右の先端間距離とし、参考配置原点：J1=(6.835, 25.000)mm、J2=(53.165, 25.000)mm、J2回転180°。各舌片突出長6.2mm、左右の肩位置X≈6.2mmと53.8mm、中央本体長≈47.6mm。接続点はフットプリントの元の座標から厳密に算出し、上下約0.005mmの非対称を勝手に補正しない。
- 本体上下端をY=0と50mmとした単一閉じたEdge.Cutsを作成する。フットプリント側既存Edge.Cutsと外形を途切れなく連結する。USB端子以外の全周加工・角R・外形はGerber生成時の確認事項。
- 2つの端子の各回路は電気的に**完全独立**。`GND_14` と `GND_10`、`VBUS_14` と `VBUS_10`、CCは別ネット。分割GND銅箔は互いに接続しない。**両端同時接続禁止**を基板シルクと取扱説明に表示。誤接続状態での通電/グランド共有を避けるため、未使用側の指接触にも注意。
- 基板表面の中央部に「USB2 14P」「PWR ONLY 10P (EXPERIMENTAL)」の印字を配置。Rev.T1、基板ID、LED機能、RTS試験方法を印字。コネクター差込部にはシルクを配置しない。
- 現行Rev.0.4の**GND-Edge.Cuts ≈0.17mm**（通常JLCPCB加工参考≧0.20mm）は残る。メーカーのDFM承認前に量産・製造確定扱いしない。端子の面取り/段差/外形最適化をメーカーが無断で行わないよう照会する。

## 2. 回路ブロック（14P DATA側: USB Full-Speed接続検証）
```
J1 14P (USB Type-C plugを受ける印刷端子)    USB UART (U1: WCH CH340N, SOP-8)
A1/A12/B1/B12 GND  ------------------------  GND_14  (U1 pin 3)
A4/A9/B4/B9 VBUS ---------------------------  VBUS_14 (U1 pin 5 VCC)
A5 CC1 ------------ R1 5.1 kΩ -------------  GND_14
B5 CC2 ------------ R2 5.1 kΩ -------------  GND_14
A6/B6 D+ ----------------------------------  U1 pin 1 UD+
A7/B7 D- ----------------------------------  U1 pin 2 UD-
U1 pin 8 V3 ---- C2 0.1 µF ---------------  GND_14
U1 pin 5 VCC --- C1 0.1 µF ----------------  GND_14
VBUS_14 ----- R3 1.0 kΩ ---- LED1 緑 ------ GND_14   (PWR14、5V有り)
VBUS_14 ----- R5 2.2 kΩ ---- LED3 青 ------ U1 pin 4 RTS#  (PCによる点滅指令)
U1 pin 6 TXD ---- SJ1 (はんだジャンパ) --- U1 pin 7 RXD  (USBシリアル・ループバック)
J3 2.54mmテスト端子：VBUS_14, GND_14, TXD, RXD, RTS# （必要に応じ）
```
- 既存の14Pシンボル名：`USB_C_PCB_Edge_14P_USB2_NoShield`、フットプリント名：`USB_C_Edge_14P_USB2_NoSilk`。元の文字入りパッド番号（例`A5CC1`、`B5CC2`、`A6D+`）をそのまま使用。
- U1は**CH340N（SOP-8、1.27mmピッチ、クロック内蔵）**。5V供給とし、VCCとV3にそれぞれ0.1µFのバイパスコンデンサをGNDへ配置（V3は5V動作時にVCCへ短絡しない）。U1の回路配線はWCHメーカー資料のピン割当を基準に確定する。
- 14Pの**CC1とCC2は各々独立したRd=5.1kΩ**でGNDへ。5Vより高いPDネゴシエーションは実装しない。USB A-CケーブルではCC試験条件がC-Cケーブルと異なるため、両者を混同しない。
- USB 2.0のA/B各D+、D-は、それぞれコネクター近傍で合流し、U1へ短い配線で導く。データ線の延長ヘッダと長いスタブは避け、USB Full-Speedの再現性を優先する。
- SJ1を閉じるとCH340NのTXDとRXDが接続されPCから送ったシリアルデータがPCへ返る。**USB列挙成功だけでD+/D-双方の実用通信を証明したとは扱わず、送受信も実施**する。
- LED3はRTS#のアクティブLow出力を使い、PCのシリアル制御線操作で明滅させる。**LED3の点灯は自動USB列挙表示ではない**。小電流（概ね1～2mA）に抑え、RTS#出力負荷定格を実装前にメーカー資料で確認する。必要ならトランジスタ駆動へ変更する。
- LED1/LED3はダイオード極性・逆接を基板シルクで明示。LED1はVBUS存在の目視用であり、接触品質/CC正常を単独では保証しない。
- テスト端子J3は必要ピン数に合わせて最終決定。**USBデータD+/D-はヘッダへ長く引き出さない**（レイアウトとUSB試験の影響を避ける）。
- U1の駆動と5V系はUSBホストから給電。別電源やMCU、発振子は不要。USB-UARTドライバとテスト用のPCのみ必要。

## 3. 回路ブロック（10P POWER側: 5V/嵌合比較）
```
J2 10P（既存実験用・非規格）
A1/A12/B1/B12 GND -------------------------- GND_10
A4/A9/B4/B9 VBUS --------------------------- VBUS_10
A5 CC1 -------- R6 5.1 kΩ ----------------- GND_10
B5 CC2 -------- R7 5.1 kΩ ----------------- GND_10
VBUS_10 ------- R4 1.0 kΩ -- LED2 黄 ------ GND_10
TP10_VBUS, TP10_GND, TP10_CC1, TP10_CC2：測定ランド（必要に応じ）
```
- 既存シンボル名：`USB_C_PCB_Edge_10P_Power_NoShield`、フットプリント名：`USB_C_Edge_10P_Power_NoSilk`。
- LED2は単に5V供給を表示する。CC1/CC2の有効性は、別々のテストパッドでUSB-Cプラグ表裏向きごとの測定が必要。
- 10PはUSB Type-C Power-Onlyレセプタクルの規格条件を満たすとは主張しない。最初はLEDのみの微小負荷で試験。PD高電圧や大電流の評価は対象外。

## 4. 試験モードとLEDの意味
| LED | 色 | 対象 | 発光条件 | 言えること / 言えないこと |
|---|---|---|---|---|
| LED1 PWR-14 | 緑 | J1 14P | VBUS_14 ≈ 5V | 接点経由で電力供給。**データ通信正常とは限らない** |
| LED2 PWR-10 | 黄 | J2 10P | VBUS_10 ≈ 5V | 簡略版への電源供給。**USB規格準拠ではない** |
| LED3 RTS-USB | 青 | J1 CH340N | PCからRTSアサート（Low） | PCが制御出力を操作できる。**列挙時に自動点灯はしない** |

テスト手順:
1. 基板個体の板厚・外形・エッジバリ・突出長を測定。電源接続前に短絡とCC1/CC2抵抗をテスターで確認する。
2. **同時に1本だけ**USBケーブルを接続し、まず14P側でLED1点灯・CC有効側・PC側のCH340N認識/仮想COMポート出現を確認する。ケーブル2種類×プラグ表裏2方向の4条件。
3. SJ1を閉じてPCからUART送信→同値を受信するループバックを確認。LED3をRTS制御で手動点滅する。LED1だけでは合格にしない。ドライバ導入の可否・OS名を記録する。
4. いったん抜いた後、10P側だけを接続し、LED2点灯・CC電圧・VBUSを同条件で確認。
5. ケーブル抜去時LED消灯、差し込み不足、揺れによる瞬断、目視摩耗/欠けを記録。無理な挿抜・こじりは禁止。電流制限付きハブ/保護アダプターを優先。

| R1,R2,R6,R7 | 5.1kΩ 1% | 4 | 0805 | CC1/CC2独立Rd |

| C1,C2 | 0.1µF X7R | 2 | 0805または秋月・千石で入手しやすいサイズ | CH340N VCC、V3近接 |

- 1枚の0.8mm薄基板へTHT LEDを付ける際は**リード曲げによる荷重を避け、容易に固定可能な穴径・ピッチ**にする。0805抵抗は手はんだ可能なサイズ。
- 高密度のQFNや0.5mmピッチIC、外部水晶、マイコンの書込み工程は採用しない。
- 2層PCBを1枚に集約したことによる費用削減は見込めるが、**メーカーのサイズ別価格は未見積**。発注前に1枚構成の総額を確認する。

## 6. KiCad整合と残る判断
- **検証用PCBはこれから作成**。既存の正式USB_C_PCB_Edgeシンボル/フットプリントはそのまま配置し、その他はKiCad 10の正式標準シンボル/フットプリントを使用。簡略独自キャッシュは使用しない。
- グローバルラベルは`VBUS_14`、`USB_DP_14`、`USB_DM_14`、`USB_CC1_14`、`USB_CC2_14`、`GND_14`と10P側の独立名で統一。端子・配線・グローバルラベルは50mil格子に整列し、方向/接続点を確認。USB供給電源がERCの電源供給として認識されない場合はネットごとに適切な`PWR_FLAG`を配置する（V3出力に誤配置しない）。
- MCU関連やUSB PDコントローラーは今回不要。既存10Pの非規格性、接点0.17mm外形クリアランス、0.8mm嵌合公差、6.2mm差込長は**実機で未検証**。
- **正式なKiCad 10 ERC/DRC/実装/ガーバーの検証をしていない**。製造可否や動作成功を保証しない。
